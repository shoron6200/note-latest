# Pocketleaf Design Principles

## Design Philosophy
- Premium editorial minimalism.
- Human-designed visual experience.
- Functional simplicity.
- Consistent visual hierarchy.

## Avoid
- Generic AI dashboard layouts.
- Excessive gradients.
- Unnecessary glassmorphism.
- Random rounded cards.
- Unnecessary animations.
- Decorative elements without purpose.

## Engineering
- React Native + Expo.
- TypeScript.
- Expo Router.
- SQLite.
- Preserve existing functionality.
- Never break existing database data.

## Development Rules
- Inspect before modifying.
- Reuse existing components where appropriate.
- Avoid unnecessary dependencies.
- Test after implementation.
- Prioritize functionality over decoration.
